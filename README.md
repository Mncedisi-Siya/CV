# Mncedisi Mbhamali – CV site

Single-page CV for GitHub Pages. No build step.

- `index.html` – the whole site (styles and script inline)
- `fonts/` – self-hosted Hanken Grotesk (SIL Open Font License)
- `banner/linkedin-banner.png` – LinkedIn banner, 3168×792 (2× of 1584×396)
- `banner/banner.html` – banner source

## Publish
Settings → Pages → Deploy from a branch → `main` / root.
Site: https://mncedisi-siya.github.io/CV/

## Editing projects
All projects are in the `P` array in the script at the bottom of `index.html`
(name, category, role, dates, ongoing or not, contract value, form of contract, scope bullets).
Cards, filters, the hectare ring, dialogs and experience counts are all built from it.
Update the four headline figures in the HTML by hand if contracts are added.
